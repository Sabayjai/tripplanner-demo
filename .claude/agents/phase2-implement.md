## สิ่งที่ล็อกแล้ว (ห้ามรื้อโดยไม่ถามพ่อ)
1. Tech: Vite + แยกหลายไฟล์ (ไม่เอา HTML ไฟล์เดียว)
2. โครงจอ 3 ระดับ (ทิ้งแท็บ 1-5 ทั้งหมด): 1 ทริปของฉัน / 2 ตารางเทียบ+เคาะ+ขออนุมัติ (ศูนย์กลาง) ⇄ 3 ใบรายละเอียดทีละใบ / 4 จดเงินจริง / 5 สรุปจบทริป + ปุ่มย้อน `‹` + ชื่อขั้น + แถบขั้น 5 จุด (ห้ามลอก dropdown กระโดดขั้นของต้นแบบสาธิตไปแอปจริง)
3. เก็บข้อมูล: กุญแจเดียวก้อน `trips` ใน localStorage — โมเดลรายการต่อใบ (plan/actual แยก 4 หมวดต่อใบ)
4. เคาะตัวจริง: เคาะได้ 1 ใบ/ทริป ล็อกแผน+งบ แก้ต้องปลดล็อกก่อน (มีปุ่มถอดตัวจริง/ถอดจากรอบแบบยืนยัน) จดเงินจริงได้อย่างเดียว เห็นเหลือ/เกินทันที
5. ตารางเทียบ: ยอดขอเบิกใหญ่สุดของใบตัวจริง → ตารางเทียบทุกใบ → ปุ่มเคาะเฉพาะใบที่กรอกแล้ว ยื่นมือถือให้ภรรยาดูจอนี้ได้เลย ไม่ทำแชร์/export
6. ภาษาบนจอ: ตัวเลือก / เข้ารอบ / เคาะตัวจริง / จดเงินจริง (ห้าม Candidate/Finalize/Actual/US-00X โผล่บนจอ)
7. รอบส่งงาน: รื้อทดแทนทั้งชุดรอบเดียว (R003) เห็นจอไว

## โครงข้อมูล + กฎ (ย่อจาก Design — ทำตามนี้)
- `trips[]` key `trips`: Trip {id, ชื่อ, วันที่, ผู้ใหญ่/เด็ก, สถานะ: ร่าง/วางแผน/สรุปแล้ว}
- Candidate[] {id, ปลายทาง, คืน, งบคร่าวๆ, selected: true/false} — เพิ่ม/ลบ/แก้ไม่จำกัด
- Plan เฉพาะที่ติ๊ก selected: travel {พาหนะ=รถส่วนตัว, น้ำมัน, ทางด่วน, จุดแวะ[]}, stay {ชื่อ, ราคา/คืน, คืน, รวม=ราคา×คืน}, activities[] {ชื่อ, สถานที่, ค่าเข้า/คน, หมายเหตุเด็ก, ใครเสนอ, ที่ตั้ง: ระหว่างทาง/ใกล้ที่พัก}
- Budget {เดินทาง, ที่พัก, กิน, กิจกรรม} — ดึงจากรายละเอียดมารวมอัตโนมัติ แก้เพิ่มได้ | Actual {เดินทาง, ที่พัก, กิน, กิจกรรม} — คนละชุด จดหลัง Finalize ได้ตลอด
- Finalize {แผนที่ล็อก id, locked: true/false, งบสุดท้าย} — 1 แผน/ทริป
- Contracts: ทุกช่องไม่บังคับ เว้นว่างได้ บันทึกได้เลย รวมเฉพาะที่มี | กรอกเฉพาะแผนที่ติ๊ก | หน้าสรุปอ่านอย่างเดียว ไม่แชร์/export

## วิธีทำงาน (SADF - D + F, 2 รอบ)
1. **รอบ 1 (US-001 ถึง US-005): โครง + กรอกแผน**
   - ตั้งโปรเจกต์ Vite + ภาษาไทยล้วน + มือถือเป็นหลัก + แถบยอดรวมบนทุกหน้า
   - หน้า 1: สร้าง/แก้/ลบ/คัดลอกทริป (ปิดเปิดใหม่ข้อมูลยังอยู่)
   - หน้า 2: Candidate เพิ่ม/ลบ/แก้ไม่จำกัด + การ์ดแนวตั้ง + ติ๊ก 1+ แผนไปลงละเอียด
   - หน้า 3: รายละเอียดเฉพาะแผนที่ติ๊ก (เดินทาง: รถ+น้ำมัน+ทางด่วน+จุดแวะ 2 จุด / ที่พัก: ชื่อ+ราคา/คืน×คืน=รวม / กิจกรรม: ชื่อ+ที่+ค่าเข้า+ใครเสนอ+ระหว่างทาง/ใกล้ที่พัก)
   - เสร็จ → เปิด preview ให้พ่อกดบนมือถือ → ปรับเลย์เอาต์ที่ล้นก่อนไปต่อ
2. **รอบ 2 (US-006 ถึง US-009): งบ + ล็อก + สรุป**
   - หน้า 4: งบ 4 หมวด (เดินทาง/ที่พัก/กิน/กิจกรรม ไม่บังคับ ไม่มีเพดาน) รวมอัตโนมัติ + จด Actual แยกชุด + เห็นเหลือ/เกินทันที + Finalize ล็อกจริง (ปลดล็อกถึงแก้ได้)
   - หน้า 5: สรุป 1 หน้า (การ์ด Candidate + แผนที่เลือกกรอบสี + งบ 4 หมวด + ยอดขอเบิกตัวใหญ่สุด) ภาษาไทย ตัวเลขบาทชัด
   - ปิดทริปเป็น "สรุปแล้ว" เก็บไว้อ่านทริปต่อไป
3. ส่งมอบเป็นชิ้นที่กดตรวจได้: preview + วิธีเปิด + บันทึก `docs/work/R002/02-result.md` สั้นๆ
4. ข้อมูลไม่พอ/ขัดกัน → ขึ้น Open Question ให้พ่อตัดสิน ห้ามเดาเอาเอง

## สิ่งที่ต้องผลิต
1. โค้ดแอป Vite แยกไฟล์ (แนะนำ: แยกตามหน้า + ไฟล์เก็บข้อมูลกลาง 1 ไฟล์) รันด้วย preview ได้โดยไม่ต้องติดตั้ง
2. บันทึกผล `docs/work/R002/02-result.md` ตาม template (delivered + evidence + acceptance check)
3. สรุป Chat สั้นๆ ให้พ่อรู้ว่ากดตรงไหนตรวจอะไร
