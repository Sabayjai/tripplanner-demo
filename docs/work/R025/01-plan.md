# Work Plan · R025 ปรับจากรีวิวรอบพ่อ + หน้าสรุป 2 level

- **วันที่:** 2026-10-19
- **ที่มา:** รีวิวทุกจอ 6 ข้อ (ทำ 5 ข้อ ข้ามข้อ 2) + ขอหน้าสรุปเปิดดูรายละเอียดจดจริงได้

## สิ่งที่ทำ

- ข้อ 1: การ์ดเทียบโชว์หมวดแพงสุด + เทียบกับใบถูกสุด (+X / ✅ ถูกสุดในกลุ่ม)
- ข้อ 3: ช่องกรอกเงินใส่ comma อัตโนมัติตอนพิมพ์
- ข้อ 4: ปุ่มจัดการบอกใบ้ action ข้างใน (✏️ แก้ • 🏆 เคาะ • 🗑️ ลบ)
- ข้อ 5: สถานะทริปยุบเหลือ 3 (ทำอยู่ / รอเที่ยว / จบแล้ว)
- ข้อ 6: จดจริงเรียงตามวัน + กรุ๊ปหัวข้อรายวัน
- หน้าสรุป: เห็นงบรวมก่อน (level 1) แตะหมวดกางดูรายการจดจริง (level 2)

## ไม่ทำ

- ข้อ 2 (กล่องขอเบิกโชว์แผน vs จริง) — รอสั่งรอบหน้า
