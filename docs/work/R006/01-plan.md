# Work Plan · R006 ตารางเทียบเป็น sub-card (ไม่ต้องมี label)

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อเสนอ — ทำเป็น sub-card จะดูดีกว่า ไม่ต้องใส่ label อ่านก็เดาได้แล้ว

## 1. สิ่งที่ทำ

- ทิ้ง `<table>` ทั้งจอ — ตัวเลือกแต่ละใบเป็นการ์ดย่อย (แตะทั้งใบเปิดได้) ประกอบด้วย: ชื่อสีน้ำเงิน + › / คืน • ข้อดี / คร่าวๆ X / ละเอียด Y / ป้ายสถานะ / ปุ่ม 2 ปุ่ม + ปุ่มเคาะ
- ไม่มีหัวคอลัมน์ (ทางเลือก/คร่าวๆ/ละเอียด) อีก — เหลือแค่คำใบ้เล็กๆ ในบรรทัดที่ต้องเดา (คร่าวๆ/ละเอียด) ซึ่งอ่านเดาได้เอง
- กล่องขอเบิกใบตัวจริงคงเดิม (เป็นการ์ดอยู่แล้ว)

## 2. เกณฑ์ตรวจรับ

- [ ] พ่อเห็นการ์ดแล้วเดาออกโดยไม่ต้องมีหัวตาราง
