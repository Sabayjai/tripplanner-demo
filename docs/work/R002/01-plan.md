# Work Plan · R002 ทริปครอบครัว (Design → Deployment)

- **ชื่องาน / รอบงาน:** R002 - ออกแบบ + สร้าง + ปล่อย Trip Planner ครอบครัว
- **ผู้รับผิดชอบ:** AI (ผู้ลงมือ) / พ่อ (ผู้ตรวจรับ)
- **วันที่:** 2026-10-18
- **อ้างอิง Requirement:** `docs/requirements/family-trip.md` (ACCEPTED, 9 US)

---

## 1. เป้าหมาย (Goal)
- ได้แอป Trip Planner ใช้ได้จริงบนมือถือพ่อ ครบ 9 US ตั้งแต่สร้างทริป → Candidate → ลงละเอียด → งบ 4 หมวด → Finalize → จดจริง → สรุป 1 หน้า
- เห็นจอจริงไว ปรับเลย์เอาต์มือถือได้ก่อนล็อกทั้งหมด

## 2. สิ่งที่ล็อกแล้ว (Locked Decisions)
1. Tech: B - Vite + แยกหลายไฟล์ (ไม่เอา HTML ไฟล์เดียวเพราะยาวไป)
2. หน้าจอ: A - 5 หน้า (ลิสต์ทริป / Candidate / รายละเอียด / งบ+จดจริง / สรุป)
3. เก็บข้อมูล: A - กุญแจเดียวก้อน `trips` (สมุดเล่มเดียว) + ปุ่มคัดลอกข้ามทริป (แบบที่ 1)
4. งบ + Finalize: A - ล็อกแผน+งบหลัง Finalize, จด Actual ได้อย่างเดียว, ติดป้ายกลุ่มอัตโนมัติตามหน้าที่กรอก, งบรวมอัตโนมัติ, แยกชุดแผน vs จ่ายจริง, มีแถบยอดรวมบนทุกหน้า
5. หน้าสรุป: A - ตารางเทียบ + สรุปงบหน้าเดียว แบบการ์ดแนวตั้งบนมือถือ / ตารางบนจอใหญ่ ยอดขอเบิกตัวใหญ่สุดบนสุด
6. รอบส่งงาน: B - แบ่ง 2 รอบ เห็นจอไว (AI แนะนำ พ่อไม่มีความเห็นเพิ่มเติม)

## 3. ขอบเขตงาน (Scope)
- **รอบ 1 (US-001 ถึง US-005): โครง + กรอกแผน**
  - [ ] ตั้งโปรเจกต์ Vite + ภาษาไทยล้วน + มือถือเป็นหลัก
  - [ ] หน้า 1 ลิสต์ทริป (สร้าง/แก้/ลบ/คัดลอกข้ามทริป) + เก็บก้อนเดียว
  - [ ] หน้า 2 Candidate (เพิ่ม/ลบ/แก้ไม่จำกัด + ตารางเทียบแบบการ์ด + ติ๊ก 1+ แผนไปลงละเอียด)
  - [ ] หน้า 3 รายละเอียด (เดินทาง: รถ+น้ำมัน+ทางด่วน+จุดแวะ 2 จุด / ที่พัก: ชื่อ+ราคา/คืนxคืน=รวม / กิจกรรม: ชื่อ+ที่+ค่าเข้า+ใครเสนอ+ติ๊กระหว่างทาง/ใกล้ที่พัก)
  - [ ] แถบยอดรวมบนทุกหน้า
- **รอบ 2 (US-006 ถึง US-009): งบ + ล็อก + สรุป**
  - [ ] หน้า 4 งบ 4 หมวด (เดินทาง/ที่พัก/กิน/กิจกรรม ไม่บังคับ ไม่มีเพดาน) + ดึงยอดจากรายละเอียดมารวมอัตโนมัติ + จด Actual แยกชุด + เห็นเหลือ/เกินทันที
  - [ ] Finalize 1 แผน/ทริป + ล็อกแผน+งบ แก้ต้องปลดล็อกก่อน
  - [ ] หน้า 5 สรุป 1 หน้า (การ์ด Candidate + แผนที่เลือก + งบ 4 หมวด + ยอดขอเบิก) ดูบนเครื่องพ่อ ไม่ทำแชร์/export
  - [ ] ปิดทริปเป็น "สรุปแล้ว" เก็บไว้อ่านทริปต่อไป
- **ไม่ทำ (Out of Scope):**
  - จอง/จ่ายเงินจริง, login หลายคน, sync ข้ามเครื่อง, ทริปต่างประเทศ, แนบรูปใบเสร็จ, PWA/service worker

## 4. เกณฑ์การตรวจรับ (Acceptance Criteria)
- [ ] รอบ 1: สร้างทริปหลายทริปได้ ปิดเปิดใหม่ข้อมูลยังอยู่, Candidate เพิ่ม/ลบ/แก้ไม่จำกัด เห็นเทียบในจอเดียว ติ๊กไปลงละเอียดได้, รายละเอียดครบเดินทาง/ที่พัก/กิจกรรมตาม US-003 ถึง US-005
- [ ] รอบ 2: งบ 4 หมวดรวมอัตโนมัติ ไม่บังคับกรอก, Finalize ล็อกจริง ปลดล็อกถึงแก้ได้, จดจริงแยกหมวดเห็นเหลือ/เกินทันที, หน้าสรุปจอเดียวภาษาไทยตัวเลขบาทชัดบนมือถือ
- [ ] เปิด preview บนมือถือได้ทั้ง 2 รอบโดยไม่ต้องติดตั้ง

## 5. ขั้นตอน Deployment
1. รอบ 1 เสร็จ → เปิด preview ให้พ่อกดบนมือถือ → ปรับเลย์เอาต์ถ้าล้น
2. รอบ 2 เสร็จ → preview รวม 9 US → ตรวจ acceptance ทั้งหมด
3. ส่งมอบไฟล์ + วิธีเปิดใช้ + บันทึก result (02-result.md)

## 6. ข้อสังเกต / ปรับทีหลังได้
- เลย์เอาต์การ์ดแนวตั้งยึดก่อน เห็นจอจริงแล้วปรับได้ตามที่พ่อขอ
- ข้อมูลเป็นตัวหนังสือล้วน (localStorage แปลงตัวเลข/วันที่ให้เอง) โควต้า ~5MB พอสำหรับทริปปีละไม่กี่รอบแบบไม่มีรูป
- ถ้าอนาคตอยาก sync/หลายคน ต้องรื้อที่เก็บใหม่ (อยู่นอก scope รอบนี้)
