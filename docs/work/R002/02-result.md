- แถบยอดรวมบนทุกหน้า: เดินทาง + ที่พัก + กิจกรรม + กิน = รวม อัปเดตทันที

- กดที่ตัวการ์ดเปิดทริปได้เลย (พ่อเข้าใจว่าปุ่ม "เปิด" เป็นป้ายสถานะ): `trips.js` เพิ่ม card.onclick (เว้นปุ่มข้างใน) ทดสอบกดชื่อการ์ดสลับทริปได้จริง
