# Work Plan · R021 ปลดล็อกจากหน้าจดจริง = กลับขั้นเทียบ ยังไม่เคาะ

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อ — ปลดล็อกจากหน้า Actual ต้องกลับไปหน้า Candidate สถานะคือยังไม่เคาะแผน

## สิ่งที่ทำ

- ปุ่มในหน้าจดจริงเปลี่ยนเป็น “↩ กลับไปขั้นเทียบ” — กดแล้วถอนการเคาะทั้งหมด (อนุมัติหลุด, กลับตารางเทียบ, สถานะยังไม่เคาะ) ยอดจดจริงค้างที่ใบเดิม เคาะซ้ำได้
- ปุ่ม “🔓 ปลดล็อกแก้” ในตารางเทียบคงเดิม (เปิดแผนให้แก้โดยยังเป็นแผนที่เลือกอยู่) — สองปุ่มความหมายต่างกันตามชื่อแล้ว
