# Work Plan · R022 รายการจดจริงมีวันที่ประกบ

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อถาม — บันทึก Actual ไม่มีวันที่ประกบหรือ?

## สิ่งที่ทำ

- ฟอร์มจดจริงเพิ่มช่องวันที่ (ปฏิทินมือถือ, ค่าเริ่มต้น = วันนี้, ไม่บังคับเปลี่ยนก็ได้)
- แถวรายการโชว์ป้ายวันที่ไทยสั้นๆ (เช่น 📅 30 ต.ค.)
- รายการเก่าที่ไม่มีวันที่โชว์แบบเดิม (ไม่พัง)
