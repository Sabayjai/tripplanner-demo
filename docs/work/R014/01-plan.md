# Work Plan · R014 ปุ่มเงียบ + การ์ดโชว์ของในใบ

- **วันที่:** 2026-10-18
- **ที่มา:** ฟีดแบ็กพ่อ — ปุ่มเด่นเกิน + ไม่เห็นรายละเอียดตัวเลือก เห็นแค่ข้อดีกับยอดเงิน

## สิ่งที่ทำ

1. ปุ่ม “⋯ จัดการ” เป็นปุ่มเงียบ (ตัวหนังสือเทาเล็กชิดขวา ไม่มีกรอบเต็มกว้าง) — การ์ดโล่ง ตาไม่สะดุด
2. การ์ดโชว์ของในใบแบบย่อ (เฉพาะหมวดที่กรอกแล้ว): 🚗 ยอด+จุดแวะ / 🏠 ชื่อที่พัก+ยอด / 🍜 ชื่อ/จำนวนอย่าง+ยอด / 🎡 ชื่อกิจกรรม+ยอด — เทียบได้โดยไม่ต้องเปิดใบ
