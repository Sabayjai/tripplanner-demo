# Work Plan · R012 ตัด toggle ทิ้ง — กรอกได้ทุกใบ + บอกแค่แผนที่เลือก

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อ — toggle ให้ความหมายผิด, จริงๆ กรอกได้ทุกใบก็พอ บอกแค่ใบไหนคือแผนที่เลือก+ล็อกแล้ว

## สิ่งที่ทำ

- ตัดสวิตช์/ปุ่มดาว/ขั้นเข้ารอบทิ้งทั้งหมด — เปิดใบไหนก็กรอกละเอียดได้เลย
- การ์ดบอกแค่: คร่าวๆ/ละเอียด + สถานะ (🏆 แผนที่เลือก · ล็อกแล้ว / ยังไม่กรอก) + ปุ่มแก้ + ปุ่มเคาะ/เปลี่ยนเป็นใบนี้
- คำว่า “ตัวจริง/เข้ารอบ/★☆” หายจากจอทั้งหมด เหลือ “แผนที่เลือก” + “ล็อก”
- เปลี่ยนตัวจริงตรงได้เหมือนเดิม (R011) + ย้อนปรับได้เหมือนเดิม (R010)
