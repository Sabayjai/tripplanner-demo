# Work Plan · R013 พับปุ่ม + ลบใบจากการ์ด + popup เข้าธีม

- **วันที่:** 2026-10-18
- **ที่มา:** ฟีดแบ็กพ่อ 3 ข้อ (การ์ดโดนปุ่มกินที่ / ลบใบจากการ์ด / popup เข้าธีมตะมุตะมิ)

## สิ่งที่ทำ

1. การ์ดเหลือปุ่มเดียว “⋯ จัดการใบนี้” — กดค่อยกางปุ่ม action (แก้/เคาะ-เปลี่ยน/ลบ) การ์ดเลยโล่ง
2. ลบใบได้จากการ์ดเลย (มีถามก่อน ถ้าเป็นแผนที่เลือกก็ถอดให้ด้วย)
3. `src/modal.js` ใหม่ — popup ถามเข้าธีมแทน browser confirm/alert ทั้งหมด (emoji เด้งๆ การ์ดขอบมน คลิกนอกกล่อง = ยกเลิก) แทน 9 จุด: ลบทริป/ลบใบ(2ทาง)/เคาะ/เปลี่ยนแผน/ถอดแผน/ปลดล็อก(2ทาง)/จบทริป/เปิดทริปอีกครั้ง
4. Flow เดิมทุกอย่าง ไม่เพิ่มฟีเจอร์
