## 2. เคาะแล้วถือว่าอนุมัติทันที (ตัดขั้น “ออกเดินทาง” ทิ้ง)

- กดเคาะ = ล็อก + อนุมัติ + ไปจดเงินจริงได้เลย (ตั้ง departed ทันที, ทำต่อวิ่งเข้าจดเงินจริง)
- กล่องขอเบิกเหลือปุ่มเดียว “ไปจดเงินจริง →” (ยังยื่นมือถือให้ภรรยาดูจอนี้ได้เหมือนเดิม)
- เปลี่ยนใจยังได้: ถอดตัวจริง (ยอดจดจริงค้างที่ใบเดิม) หรือปลดล็อกกลับไปแก้แผนจากหน้าจดจริง (ปุ่มใหม่เล็กๆ ใต้ปุ่มจบทริป)
- ข้อมูลเก่า/seed: ใบตัวจริงเดิมถือว่าอนุมัติแล้วทั้งหมด (migrate ตั้ง departed ให้)
