# Work Plan · R008 ปุ่มดาวเป็นสวิตช์ toggle

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อถาม — ปรับเข้ารอบให้เป็น toggle จะเข้าใจง่ายกว่าไหม (ตอบ: ใช่ เลยทำ)

## สิ่งที่ทำ

- การ์ดแต่ละใบเหลือปุ่มกดแค่ 2: สวิตช์ ★ (เปิด = เข้ารอบสีน้ำเงิน / ปิด = คุยอยู่สีเทา เห็นสถานะในตัว) + ปุ่ม “✏️ แก้ข้อมูลใบนี้” เต็มกว้าง
- แถวสถานะรวมยอดละเอียดอยู่ในบรรทัดเดียวกับสวิตช์ (ไม่แสดงซ้ำซ้อน)
- พฤติกรรมเดิม: ถอดจากรอบยังถามยืนยัน, ใบตัวจริงไม่มีสวิตช์ (ถอดผ่าน “ถอดตัวจริง”)
