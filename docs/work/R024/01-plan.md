# Work Plan · R024 ซ่อนทริปที่จบแล้ว + หาเจอ

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อ — ทริปที่จบแล้วรกจอ ขอซ่อนแต่ต้องหาเจอ

## สิ่งที่ทำ

- หน้า “ทริปของฉัน” โชว์เฉพาะทริปที่กำลังทำ ทริปที่จบแล้ว (สรุปแล้ว) ย้ายไปอยู่ใต้ที่พับ “📦 ทริปที่จบแล้ว (N)” — กางออกแตะทำต่อได้เหมือนเดิม (วิ่งไปหน้าสรุป)
- ถ้าไม่มีทริปค้างจะบอกว่าทริปจบอยู่ด้านล่าง (ไม่ทิ้งจอว่างงงๆ)
