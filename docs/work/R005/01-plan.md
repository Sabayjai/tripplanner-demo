# Work Plan · R005 ตารางเทียบแน่นไป + “เปิดใบ” ไม่ get

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อดูจอจริง — ตารางเทียบแน่นไป, ปุ่ม “เปิดใบ” ไม่ get

## 1. ลดความแน่น + ตัดคำที่พ่อไม่ get

- ตัดปุ่ม “เปิดใบ ›” ทิ้งทั้งจอ — เหลือทางเข้าใบทางเดียวที่ชัด: **ชื่อทางเลือกสีน้ำเงินตัวใหญ่ + ›** แตะได้ทั้งชื่อและทั้งแถว
- ปุ่มในแถวเหลือ 2 ปุ่ม (☆ เข้ารอบ/★ รอบ + ✏️ แก้) + ปุ่มเคาะเฉพาะใบที่กรอกแล้ว
- เพิ่มช่องไฟแถว (padding 10px) + hover
- ข้อความสถานะใบที่คุยอยู่เหลือแค่ “○ คุยอยู่”, hint เหลือ “แตะชื่อทางเลือกเพื่อเข้าไปกรอก”

## 2. เกณฑ์ตรวจรับ

- [ ] พ่อแตะชื่อทางเลือกแล้วรู้ว่าเข้าใบได้โดยไม่ต้องมีใครบอก
- [ ] จอดูโล่งขึ้น ปุ่มไม่ล้น
