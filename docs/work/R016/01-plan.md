# Work Plan · R016 Audit popup ทุกจอ + ปุ่มซ่อนกลไกเดียว

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อขอ review — popup ขาดตรงไหน + ปุ่มซ่อนควรเหมือนกันไหม

## ผล audit (ไล่ทุก action ทุกจอ)

- ขาด 2 จุด: ปุ่ม “ออกเดินทาง” (compare, ข้อมูลเก่า) กับตั้งสถานะ “สรุปแล้ว” ในจอแก้ทริป (ปิดทริปเงียบๆ) → เติม popup ทั้งคู่
- ที่เหลือครบแล้ว: ลบ (ทริป/ใบ/รายการ/จุดแวะ), เคาะ/เปลี่ยน/ถอดแผน, ปลดล็อก (2 ทาง), จบทริป, เปิดทริปอีกครั้ง
- ไม่ต้องถาม: บันทึกทั่วไป, ล็อกกลับ (ย้อนได้ทันที ไม่หายอะไร), เปิดดูเฉยๆ

## ปุ่มซ่อน → กลไกเดียว

- การ์ด ⋯ แบบ custom (JS สลับ hidden) รื้อเป็น `<details class="more">` เหมือนฟอร์ม +เพิ่ม ทุกประการ (กาง/พับฟรี เข้าถึงดีกว่า โค้ดน้อยลง)
- หน้าตาต่างกันตามหน้าที่เหมือนเดิม: ⋯ เทาเล็ก (action รอง) vs ปุ่มกรอบน้ำเงิน (สร้างรายการ) — พฤติกรรม “แตะค่อยกาง” เหมือนกันหมด
