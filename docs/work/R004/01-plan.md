# Work Plan · R004 แก้ตามฟีดแบ็กพ่อ (3 หัวข้อแรก)

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อกดจอจริงแล้ว — ข้อ 1 ผ่าน, ข้อ 2-3 ติด

## 1. ข้อ 2 · ตารางเทียบสะดุด (ไม่รู้ว่าแตะแถวได้ + ปุ่มเรียงแนวตั้งเปลืองที่)

- แถวมี affordance: hover + เครื่องหมาย › หลังชื่อใบ + ปุ่ม “เปิดใบ ›” ชัดเจนทุกแถว (แตะแถว/ปุ่มได้เลย ไม่ต้องกดดาวก่อน)
- ปุ่มในแถวเรียงนอนแถวเดียวเสมอ (★ รอบ/☆ เข้ารอบ มีชื่อกำกับ + ✏️ + เปิดใบ ›) ปุ่มดาวกดแล้วรู้ว่าคืออะไร
- ใบที่ยังไม่เข้ารอบ: แตะแล้วเจอปุ่มเดียวจบ “★ เข้ารอบ + กรอกละเอียดใบนี้ →” ไม่ตัน

## 2. ข้อ 3 · การ์ดเดินทางกรอกไม่รู้เรื่อง (ไม่รู้เก็บอะไร)

- การ์ดเดินทางแยก 3 ส่วนมีเลขกำกับ: ① ไปด้วยอะไร (พิมพ์แล้วเซฟเอง ไม่ต้องกดบันทึก) ② ค่าใช้จ่าย (หัวข้อ+ยอด+โน้ต) ③ จุดแวะพัก (เพิ่ม/ลบทีละจุด)
- ทุกการ์ดมีคำใบ้วิธีกรอก: ที่พัก “ใส่ราคา/คืนกับจำนวนคืน ระบบคูณให้เอง” / กิจกรรม “ใส่ค่าเข้า/คน ระบบคูณจำนวนคนให้เอง” / กิน “จดทีละมื้อก็ได้”
- ฟอร์มที่พัก/กิจกรรมโชว์ตัวอย่างยอดสดขณะพิมพ์ (เช่น 2,200 × 2 = 4,400)

- [ ] ปุ่มในตารางไม่ล้นจอบนมือถือพ่อ
- [ ] กรอกพาหนะ จุดแวะ ที่พัก กิจกรรม ได้โดยไม่งง (พ่อกดซ้ำ)
