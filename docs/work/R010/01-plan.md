# Work Plan · R010 เคาะแล้วย้อนมาปรับได้

- **วันที่:** 2026-10-18
- **ที่มา:** พ่อ — “แต่ก็ต้องย้อนมาปรับได้เหมือนกัน” (เคาะ = อนุมัติทันที แต่ต้องกลับมาแก้ได้)

## สิ่งที่ทำ (ย้อนได้ทุกทาง ล็อกเฉพาะใบตัวจริง)

1. ล็อกเฉพาะใบตัวจริง — ใบอื่นกลับมาแก้ได้เสมอแม้ล็อกอยู่
2. ตารางเทียบ (อนุมัติแล้ว): ปุ่ม “🔓 ปลดล็อกแก้” → กลับใบตัวจริงที่แก้ได้ → แก้เสร็จกด “🔒 ล็อก” กลับ (ปุ่มสลับกันตามสถานะ)
3. หน้าจดจริง: ปุ่มปลดล็อกคงเดิม แต่ไม่ถอนการอนุมัติแล้ว (อนุมัติยังอยู่ ยอดจดจริงไม่หาย)
4. ถอดตัวจริงยังมีเหมือนเดิม (ยอดทุกอย่างค้างที่ใบเดิม เคาะใหม่ได้)
