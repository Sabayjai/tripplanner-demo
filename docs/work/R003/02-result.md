## 2. หลักฐานการตรวจรับ (Evidence)

- `cd app && npm run build` — ผ่าน (vite v5, 12 modules)
- `node --check` ทุกไฟล์ src — ผ่าน 9/9
- เทส store 16 ข้อ — ผ่านหมด: seed ใบ A รวม 6,450 / เคาะ→รอเดินทาง→ทำต่อเข้าตารางเทียบ / ออกเดินทาง→จดเงินจริง / จด 6,900 เกิน 450 / จบทริป→สรุป / migrate ข้อมูลเก่าครบ (ยอด 6,900 + จุดแวะ/พาหนะอยู่) / ทริปว่าง=ร่าง
- `npm run preview` — serve HTTP 200, bundle ใหม่มีข้อความ 3 จอหลักครบ
- เทสกดจอจริงด้วย jsdom (harness นอกโปรเจกต์ กดผ่าน handler จริงทุกจอ) 25/25 ข้อ: สร้าง “ทริปวันฮาโลวีน 29–31 ต.ค. ผู้ใหญ่ 2 เด็ก 2” → 2 ใบ (ทะเลระยอง/เขาใหญ่) → เข้ารอบทั้งคู่ → ลงละเอียดระยองรวม 9,240 (เดินทาง 2,040 + ที่พัก 4,400 + กิน 1,200 + กิจกรรม 1,600 คิดค่าเข้า/คน×4) / เขาใหญ่รวม 5,500 → ตารางเทียบโชว์ยอดละเอียด 2 ใบจอเดียว → เคาะระยอง กล่องขอเบิก 9,240 → ออกเดินทาง → จดจริง 5 รายการรวม 8,220 เหลือ 1,020 → จบทริปสรุป + บทเรียน → ปิดเปิดใหม่ข้อมูลครบ
