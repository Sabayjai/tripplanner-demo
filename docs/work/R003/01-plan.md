- **ผู้รับผิดชอบ:** AI (ผู้ลงมือ) / พ่อ (ผู้ตรวจรับ)
- **วันที่:** 2026-10-18
- **อ้างอิง:** `docs/requirements/family-trip.md` (ACCEPTED, 9 US) + `docs/design/ux-redesign.md` (ACCEPTED) + `docs/design/ux-prototype.html` (ต้นแบบกดเล่นได้)

---

## 1. เป้าหมาย (Goal)

รื้อแอป `app/` จากแท็บ 5 หน้าเดิมเป็นทริป 3 ระดับตามต้นแบบใหม่ทั้งชุด (ไม่ปะผุ) ครบ 9 US เดินเรื่องได้ 1 รอบ: ทริปของฉัน → เทียบ+เคาะ+ขออนุมัติ → ลงละเอียดทีละใบ → จดเงินจริง → สรุปจบทริป

## 2. สิ่งที่รื้อ (แทนของเก่า)

1. `store.js`: โมเดลรายการต่อใบ (plan/actual แยก 4 หมวดต่อใบ) + `tripStatus`/`continueTarget` ดูขั้นจากข้อมูล + migrate ข้อมูลเก่าอัตโนมัติ (น้ำมัน/ทางด่วน/ที่พัก/กิจกรรม/งบเดิมย้ายเข้ากองรายการ ไม่หาย)
2. `main.js` + `index.html`: ทิ้ง `TABS` + แถบยอดรวมข้ามใบ เปลี่ยนเป็น router 3 ระดับ (ทริป/ห้องทริป/ใบ) + แถบขั้น 5 จุด + ปุ่มย้อน `‹` เข้าแอปเจอทริปของฉันเสมอ
3. `pages/`: 7 จอใหม่ (trips/tripEdit/compare/candEdit/detail/actual/final) ลบจอเก่า (candidates/details/budget/summary) ตารางเทียบเป็นศูนย์กลาง เคาะ+ขออนุมัติจบจอเดียว ใบรายละเอียดโครงเดียวกับจดเงินจริง
4. `style.css`: ล็อกตามต้นแบบ (ปุ่มหลักเต็มกว้าง 55px ปุ่มเดียวต่อจุดตัดสินใจ, ปุ่มย่อในตาราง, ฟอร์มพับกดค่อยกาง, `.wrap` 560px ทุกจอ)
5. ภาษาบนจอ: ตัวเลือก/เข้ารอบ/เคาะตัวจริง/จดเงินจริง ห้ามศัพท์เทคนิค

## 3. เกณฑ์การตรวจรับ (Acceptance Criteria)

- [ ] เปิดแอปรู้ทันทีว่าทริปไหนค้างขั้นไหน (ป้ายสถานะจากการ์ด)
- [ ] เทียบใบทั้งหมดในจอเดียวโดยไม่ต้องมุด + เคาะ+ขออนุมัติจบจอเดียว
- [ ] กรอกใบทีละใบ รู้ตลอดว่ากำลังกรอกใบไหนของทริปอะไร
- [ ] จดเงินจริงทีละรายการ เห็นเหลือ/เกินทันที
- [ ] ยื่นมือถือให้ภรรยาดูจบในจอตารางเทียบ + สรุปจบทริปหลังกลับ
- [ ] ข้อมูลเก่า (ถ้ามี) migrate มาครบ ยอดไม่หาย

## 4. ไม่ทำ (Out of Scope — เหมือนเดิม)

จอง/จ่ายเงินจริง, login หลายคน, sync ข้ามเครื่อง, ทริปต่างประเทศ, แนบรูปใบเสร็จ, PWA/service worker, ปุ่มแชร์/export/sync, dropdown กระโดดขั้นของต้นแบบสาธิต
