# Work Plan · R011 สวิตช์ความหมายเดียว + เปลี่ยนตัวจริงตรงได้

- **วันที่:** 2026-10-18
- **ที่มา:** ฟีดแบ็กพ่อ 2 ข้อ

## 1. สวิตช์ให้ความหมายผิด → แยกสถานะออกจากสวิตช์

- ป้ายสถานะเป็นตัวแสดงอย่างเดียว (○ คุยอยู่ / ★ เข้ารอบ · ยอด / 🏆 ตัวจริง)
- สวิตช์มีความหมายเดียว: เข้ารอบ on/off — ใบตัวจริงไม่มีสวิตช์ (กดแล้วไม่เกิดอะไรขึ้นแบบเดิมหายไป ถอดที่กล่องขอเบิก)

## 2. กลับมาแก้ = เลือกใหม่ตรงได้เลย

- ใบที่กรอกแล้วมีปุ่ม “เปลี่ยนเป็นใบนี้ 🏆” แม้เคาะไปแล้ว (confirm บอกว่ายอดจดจริงค้างใบเดิม)
- เคาะครั้งแรกยังเรียก “เคาะใบนี้ 🏆” เหมือนเดิม
