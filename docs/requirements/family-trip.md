# ทริปครอบครัวในประเทศ (งบน้อย) — ACCEPTED

> หมายเหตุ: ทะเลเป็นแค่ Candidate ตัวอย่าง ยังไม่ล็อก — ร่างหลายแผนคุยรอบแรก → ลงละเอียด 1+ แผน → Finalize → บันทึก cost วันจริง → สรุปจบทริป

## 1. ข้อมูลภาพรวม (Overview)
- **ชื่อระบบ/ฟีเจอร์:** Trip Planner ครอบครัว — วางแผนทริปพักผ่อนในประเทศ + คุมงบ (หลายทริปต่อปี)
- **เป้าหมายหลัก:** ระบบเดียวครบวงจรแบบง่าย — วางแผนก่อนทริป (ร่าง Candidate + ลงละเอียด + Finalize) แล้วบันทึก cost จริงระหว่าง/หลังทริป จบทริปสรุปเก็บไว้เป็นบทเรียนทริปต่อไป โดยพ่อเป็นคนบันทึกทั้งหมด ตัวเลขทุกอย่างไม่บังคับ (ไม่มีเพดาน/จำนวนคืน/ปลายทาง fix)
- **ผู้ใช้งาน (Users):** พ่อ (คนเดียวที่เป็นคนบันทึกใน App) / ภรรยา+ลูก (ช่วยคิด ช่วยหากิจกรรม ร่วมเลือกแผน แต่ไม่ได้กดใน App — ข้อจำกัดยังไม่มี Backend)

## 2. ขอบเขต (Scope)
- **สิ่งที่ระบบทำได้ (In Scope):**
  - สร้างทริปได้หลายทริป (ปีหนึ่งเที่ยวได้หลายรอบ): ชื่อทริป, ช่วงวันที่ (ยืดหยุ่นตามวันหยุด), จำนวนคน, สถานะทริป (ร่าง/วางแผน/สรุปแล้ว)
  - ร่าง Candidate ได้ไม่จำกัด ไม่ fix ประเภท (ทะเล/เขา/เมืองเป็นแค่ตัวอย่าง draft) เพิ่ม/ลด/แก้ได้ตลอด เอาไว้คุยรอบแรก
  - เลือก 1+ แผนไปลงรายละเอียด: เดินทางไป-กลับ + จุดแวะ / ที่พัก (จำนวนคืน-ราคาไม่บังคับ) / กิจกรรม (ช่วยกันหาแล้วพ่อบันทึก)
  - Finalize แผน 1 รอบก่อนเดินทาง (ล็อกแผนที่ตกลง ไม่บังคับล็อกตัวเลข)
  - ตั้งงบประมาณแยกหมวดแบบไม่บังคับ 4 หมวด (เดินทาง/ที่พัก/กิน/กิจกรรม — ไม่มีหมวดเผื่อฉุกเฉิน เพราะพ่อเตรียมแยกเอง) + บันทึก Actual cost เป็นตัวเลขง่ายๆ ระหว่างทริปไปเรื่อยๆ จบทริปสรุปเทียบงบถ้ามีงบตั้งไว้ (ไม่ถ่ายรูปใบเสร็จ)
  - สรุปหารือ+ขออนุมัติงบ 1 หน้า (เทียบ Candidate + แผนที่เลือก, ยอดขอเบิก)
  - คนบันทึกทั้งหมดคือพ่อ (ข้อจำกัด: ยังไม่มี Backend / login หลายคน)
- **สิ่งที่ยังไม่ทำในตอนนี้ (Out of Scope):**
  - ระบบจองที่พัก/จ่ายเงินจริง, login หลายคน (Backend), ทริปต่างประเทศ, sync ข้ามเครื่อง

## 3. Candidate Plans ตัวอย่าง (ยังไม่ล็อก — เอาไว้คุยรอบแรกก่อน)

| แผน | ตัวอย่าง | งบคร่าวๆ | ข้อดี | ข้อควรระวัง |
|------|----------|-----------|--------|---------------|
| A | ทะเล 2 คืน (เช่น ชะอำ/หัวหิน) | 10,000-12,000 | ลูกเล่นน้ำได้เยอะ มีกิจกรรมชายหาด | ค่าที่พัก+น้ำมันสูงสุด |
| B | เขาใกล้บ้าน 2 คืน (เช่น เขาใหญ่) | 7,000-9,000 | เดินทางสั้น ประหยัดน้ำมัน | กิจกรรมเด็กน้อยกว่าทะเล |
| C | เมือง+สวนสนุก 1 คืน | 6,000-8,000 | งบน้อยสุด ลูกสนุกแน่ | เหนื่อยเดินทาง-กลับในวันเดียว |

> ขั้นตอน: ร่าง Candidate คร่าวๆ หลายแผน → คุยกันรอบแรก → เลือก 1+ แผนไปลงรายละเอียด → Finalize อีกรอบก่อนเดินทาง → บันทึก cost วันจริง → จบทริปสรุปเก็บไว้

## 4. รายการความต้องการ (User Stories & Requirements)
### US-001 · สร้างทริปได้หลายทริป
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** สร้างทริปได้หลายทริป ระบุชื่อ ช่วงวันที่ จำนวนคน พร้อมสถานะ (ร่าง/วางแผน/สรุปแล้ว)
- **เพื่อที่จะ:** วางแผนพักผ่อนได้หลายรอบต่อปี + ดูทริปเก่าเป็นบทเรียนทริปต่อไป
- **เกณฑ์การตรวจรับ (Acceptance Criteria):**
  - [ ] สร้าง/แก้ไข/ลบทริปได้ไม่จำกัด เก็บชื่อ ช่วงวันที่ จำนวนผู้ใหญ่/เด็ก สถานะทริป
  - [ ] เห็นลิสต์ทริปทั้งหมด + เปิดดูทริปเก่าหลังปิด App แล้วเปิดใหม่ได้

### US-002 · ร่าง Candidate แบบไม่ fix + เทียบก่อนลงละเอียด
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** ร่างแผนคร่าวๆ ได้ไม่จำกัด ประเภทไม่ fix (ทะเล/เขา/เมืองเป็นแค่ตัวอย่าง) เพิ่ม/ลด/แก้ได้ตลอด
- **เพื่อที่จะ:** เอาไปคุยกันรอบแรกก่อนค่อยลงรายละเอียด
- **เกณฑ์การตรวจรับ:**
  - [ ] เพิ่ม/ลบ/แก้ Candidate ได้ไม่จำกัด แต่ละแผนมีปลายทาง จำนวนคืน งบคร่าวๆ (ทุกช่องไม่บังคับกรอก)
  - [ ] เห็นตารางเทียบในจอเดียว
  - [ ] เลือก mark 1+ แผนไปลงรายละเอียดได้

### US-003 · วางแผนเดินทาง (เฉพาะแผนที่เลือกไปลงละเอียด)
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** บันทึกวิธีเดินทางไป-กลับ + จุดแวะพักระหว่างทาง
- **เพื่อที่จะ:** คุมเวลาและค่าน้ำมัน/ทางด่วน
- **เกณฑ์การตรวจรับ:**
  - [ ] บันทึกพาหนะ (รถส่วนตัว), ระยะทาง/ค่าน้ำมันโดยประมาณ, ค่าทางด่วนได้
  - [ ] เพิ่มจุดแวะระหว่างทางได้อย่างน้อย 2 จุด

### US-004 · บันทึกที่พัก (ไม่บังคับ)
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** บันทึกที่พักพร้อมราคา จำนวนคืนยืดหยุ่นตามวันหยุด (ไม่บังคับ ไม่ fix)
- **เพื่อที่จะ:** รู้ค่าที่พักรวมก่อนขออนุมัติ (ถ้ามี)
- **เกณฑ์การตรวจรับ:**
  - [ ] บันทึกชื่อที่พัก ราคา/คืน จำนวนคืนได้ (ทุกช่องไม่บังคับ) ถ้ากรอกครบคำนวณราคารวมอัตโนมัติ
  - [ ] เห็นราคารวมที่พักในหน้าสรุปงบ (ถ้ามี)

### US-005 · หากิจกรรมให้ลูก (ช่วยกันหา พ่อบันทึก)
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** รับไอเดียกิจกรรมจากทุกคนในบ้านแล้วพ่อบันทึกเข้าแผน
- **เพื่อที่จะ:** ลูกสนุก ไม่เบื่อระหว่างทริป
- **เกณฑ์การตรวจรับ:**
  - [ ] เพิ่มกิจกรรมได้ (ชื่อ, สถานที่, ค่าเข้า/คน, หมายเหตุเด็ก, ใครเสนอ)
  - [ ] แยกได้ว่ากิจกรรมอยู่ระหว่างทางหรือใกล้ที่พัก

### US-006 · ตั้งงบประมาณแยกหมวด (ไม่บังคับ, 4 หมวด)
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** ตั้งงบแยกหมวดได้ (เดินทาง/ที่พัก/กิน/กิจกรรม) แต่ไม่บังคับ — จะไม่ตั้งเลยก็ได้ (ไม่มีหมวดเผื่อฉุกเฉิน พ่อเตรียมแยกเองอยู่แล้ว)
- **เพื่อที่จะ:** คุมงบน้อยให้อยู่ (ถ้าอยากคุม)
- **เกณฑ์การตรวจรับ:**
  - [ ] ตั้งงบได้ 4 หมวด (ทุกช่องไม่บังคับ) ถ้ากรอกเห็นงบรวมอัตโนมัติ
  - [ ] ไม่มีเพดานบังคับ ไม่มีการเตือนบังคับ (ถ้าตั้งวงเงินเองถึงจะแสดงผลเทียบให้)

### US-007 · Finalize แผนก่อนเดินทาง
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** ล็อกแผนสุดท้าย + งบสุดท้าย 1 รอบก่อนวันเดินทาง
- **เพื่อที่จะ:** ทุกคนเห็นตรงกันว่าจะไปไหน ใช้งบเท่าไหร่
- **เกณฑ์การตรวจรับ:**
  - [ ] กด Finalize ได้ 1 แผนต่อทริป พร้อมงบสุดท้ายแยกหมวด
  - [ ] หลัง Finalize แผน+งบถูกล็อก (แก้ต้องปลดล็อกก่อน)

### US-008 · บันทึก Actual cost ระหว่างทริป + สรุปจบทริป
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** จดค่าใช้จ่ายจริงเป็นตัวเลขง่ายๆ แยกหมวดไปเรื่อยๆ ระหว่างทริป แล้วสรุปจบทริป (ไม่ถ่ายรูปใบเสร็จ)
- **เพื่อที่จะ:** รู้ว่าเกิน/เหลืองบเท่าไหร่ + เก็บไว้วางแผนทริปต่อไป
- **เกณฑ์การตรวจรับ:**
  - [ ] กรอกยอดจ่ายจริงเป็นตัวเลขแยกหมวดได้ตลอดทริป (ไม่ต้องแนบรูป)
  - [ ] เห็นผลต่าง งบแผน vs จ่ายจริง + เหลือ/เกิน ทันที
  - [ ] จบทริปกดสรุปได้ เปลี่ยนสถานะเป็น "สรุปแล้ว" เก็บไว้อ่านทริปต่อไป

### US-009 · สรุปหารือ+ขออนุมัติงบ 1 หน้า (ดูบนเครื่องพ่อ)
- **ในฐานะ:** พ่อ
- **ฉันต้องการ:** หน้าสรุป 1 หน้าเทียบ Candidate + แผนที่เลือก เปิดบนมือถือพ่อให้ภรรยาดู
- **เพื่อที่จะ:** หารือเลือกแผนและขออนุมัติงบได้โดยไม่ต้องอธิบายเยอะ
- **เกณฑ์การตรวจรับ:**
  - [ ] แสดงตารางเทียบ Candidate + แผนที่เลือก งบรวมแยกหมวด ยอดขอเบิก ในจอเดียว (มือถืออ่านรู้เรื่อง)
  - [ ] ภาษาไทยล้วน ตัวเลขบาทชัดเจน
  - [ ] ไม่ต้องมีปุ่มแชร์/export/sync (ดูบนเครื่องพ่อพอ)

## 5. ข้อกำหนดอื่น ๆ (Non-functional Requirements)
- Frontend อย่างเดียว ไม่มี backend เก็บข้อมูลในเครื่องพ่อ (localStorage)
- มือถือเป็นหลัก + Responsive จอใหญ่, ภาษาไทยล้วน ตัวใหญ่กดง่าย
- ออฟไลน์แบบง่าย: ข้อมูลอยู่ในเครื่องอยู่แล้ว เปิดดูแผน/จด cost ได้โดยไม่ต้องมีเน็ต (ไม่ทำ PWA ติดตั้ง/ service worker ในรอบนี้ — ถ้าเปิดผ่านไฟล์หรือเว็บที่โหลดแล้วก็ใช้ต่อได้)
- หน้าสรุปดูบนเครื่องพ่ออย่างเดียว ไม่ทำปุ่มแชร์/export (ยื่นมือถือให้ภรรยาดูพอ อย่าทำให้ยุ่ง)

## 6. บันทึกการตัดสินใจ (Decisions — ไม่มีคำถามค้าง)
- ไม่มี Open Questions แล้ว (เคลียร์หมด)
- วงเงินรวม: ไม่ตั้งเพดาน งบทุกหมวดไม่บังคับ
- Candidate/จำนวนคืน/ที่พัก: ไม่ fix พ่อเสนอเองต่อทริป เพิ่ม/ลดได้ตลอด
- หมวดงบ: 4 หมวด (เดินทาง/ที่พัก/กิน/กิจกรรม) ไม่มีเผื่อฉุกเฉิน
- Actual cost: จดแค่ตัวเลข ไม่ถ่ายรูปใบเสร็จ
