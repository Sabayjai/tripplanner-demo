# UX Redesign · Trip Planner ครอบครัว (ออกแบบใหม่จากงานจริง)

> สถานะ: ACCEPTED (2026-10-18) → รื้อโค้ดแอปจริงตามแล้วใน R003 (ทิ้งแท็บ 5 หน้าเดิมทั้งหมด)
> ที่มา: ดีไซน์เดิม (แท็บ 1-5 + ปะผุทีละจุด) ทำให้ทุกขั้นตอนดูเป็น "เมนูชั้นเดียวกัน" ทั้งที่งานจริงเป็น **กรวยเวลา** (หลายทริป → หลายใบ → ใบเดียว → จดจริง) พ่อเลยงงว่าตัวเองอยู่ชั้นไหนของอะไร

## 2. ทำไมดีไซน์เดิมไม่ Function

1. **แท็บ 5 ปุ่มโกหก:** งานจริงเป็นกรวย (J1→J6 ตามเวลา) แต่แท็บทำให้ดูเป็น 5 ห้องที่กระโดดเข้าออกได้อิสระ พ่อเลยต้องจำเองว่าอยู่ขั้นไหน
2. **ลิสต์มีช่องกรอก:** หน้าที่ควร "มอง" (J1/J2) ดันมีฟอร์มเต็มไปหมด สมองต้องแยก "อ่าน vs กรอก" ในจอเดียว
3. **ดาว 2 ความหมาย:** ★ เคยแปลว่า "ไปลงละเอียด" แล้วถูกยืมไปแปลว่า "เข้ารอบ" แล้วมี 🏆 มาซ้อนอีก — สัญลักษณ์งอกโดยไม่มี legend
4. **ยอดรวมมั่วชั้น:** แถบน้ำเงิน sum ข้ามใบ (หลายใบรวมกัน) ทั้งที่พ่อคิดทีละใบ เลขบนจอเลยไม่ตรงเลขในหัว
5. **ไม่มี primary action:** เปิดมาหน้าไหนก็เจอปุ่มเท่ากันหมด ไม่มีปุ่มเดียวที่บอกว่า "ขั้นนี้ต้องทำอะไรต่อ"

## 3. ดีไซน์ใหม่: ทริปมี "ขั้น" ไม่ใช่ "แท็บ"

### 3.1 State machine ของ 1 ทริป (5 ขั้น — ตารางเทียบเป็นศูนย์กลาง)

```
1 ทริปของฉัน (J1) → 2 เทียบ+เคาะ+ขออนุมัติ (J2/J4/J6-ก่อนไป) ⇄ 3 ลงละเอียดทีละใบ (J3) → 4 จดเงินจริง (J5) → 5 สรุปจบทริป (J6-หลังกลับ)
```

- ตารางเทียบมี 2 ร่างในจอเดียว: ตอนคุย (เลขคร่าวๆ) กับตอนเคาะ (ยอดละเอียด + ปุ่มเคาะ + กล่องขอเบิก) — เคาะและขออนุมัติไม่แยกจออื่น

- ทริปมีขั้นเดียวเสมอ ดูจากข้อมูล (ไม่ต้องจำ): ไม่มีใบ = ร่าง / มีใบแต่ไม่มียอดละเอียด = คุย / มียอดละเอียดแต่ยังไม่เคาะ = ลงละเอียด / เคาะแล้ว = เคาะแล้ว ฯลฯ
- แต่ละขั้นมี **ปุ่มหลักปุ่มเดียว** (เช่น ขั้นคุย = "+ เพิ่มตัวเลือก", ขั้นลงละเอียด = "เคาะเป็นตัวจริง")
- ย้อนขั้นได้เสมอ (ถอดตัวจริง / ถอดจากรอบ) แต่ต้องกดยืนยัน

### 3.2 โครงจอใหม่ (3 ระดับ ไม่ใช่ 5 แท็บ)

```
ระดับ 1 · ทริปของฉัน (J1: เข้าแอปเจอจอนี้เสมอ แตะทริปไปรอถูกขั้น)
  └ ระดับ 2 · ห้องทริป (แถบขั้น 5 จุด + เนื้อหาตามขั้น)
       ├ เทียบ+เคาะ+ขออนุมัติ: ตารางเทียบทุกใบ + ปุ่มเคาะเฉพาะใบที่กรอกแล้ว + กล่องขอเบิก+ล็อกของใบตัวจริง (J2/J4/J6-ก่อนไป)
       ├ ลงละเอียด: ใบทีละใบ ฟอร์มแก้ได้ทั้งใบ (J3) — กรอกเสร็จกลับมาเคาะที่ตารางเทียบ
       ├ จดเงินจริง: สมุดบัญชีทีละรายการแยก 4 หมวด (J5)
       └ สรุปจบทริป: อ่านอย่างเดียว (J6-หลังกลับ)
```

<!-- BUILD-NOTE: dropdown กระโดดขั้น + จอ ✏️ ในต้นแบบมีไว้สาธิต ห้ามลอกไปแอปจริง (แอปจริงใช้ปุ่มย้อน + ชื่อขั้นเท่านั้น) -->

- **ทิ้งแถบแท็บ 1-5 ทั้งหมด** แทนด้วย: ปุ่มย้อน (`‹`) + ชื่อชั้นปัจจุบัน (`ทริปชะอำ › เขาใหญ่`) + แถบขั้น (dots 6 จุด)
- **ยอดเงินมี 2 ที่เท่านั้น:** ยอดของใบนั้น (บนใบ) กับยอดขอเบิก (หน้าสรุป) — ไม่มีเลข sum ข้ามใบบนแถบน้ำเงินอีก
- **งบคร่าวๆ vs ยอดละเอียดแยกกันชัด:** คร่าวๆ อยู่ในตารางเทียบ (เลขคุย) / ละเอียดอยู่บนใบ (เลขกรอก) / หน้างบเทียบ 2 เลขข้างกัน

### 3.3 ภาษาบนจอ (พ่ออ่าน ไม่ใช่ช่างอ่าน)

| ห้ามใช้ | ใช้แทน |
|----------|--------|
| Candidate / Finalize / Actual | ตัวเลือก / เคาะตัวจริง / จดเงินจริง |
| selected / promote / drilldown | เข้ารอบ / เคาะ / มุดเข้าไป |
| US-00X, stage, pick | ห้ามโผล่บนจอเด็ดขาด |

### 3.4 Pattern ปุ่ม + Layout (ล็อก — ทุกจอเหมือนกัน)

- ปุ่มหลัก: เต็มกว้าง สีทึบ ตัว 18px ปุ่มเดียวต่อจุดตัดสินใจ (สูง 55px เท่ากันทุกจอ — ใช้ border โปร่งใส 2px ให้เท่าปุ่มรอง)
- ปุ่มในการ์ดไม่ต้องเต็มความกว้างการ์ด: ชิดขวา ขนาดตามเนื้อหา (หลักทึบ + รองโปร่ง สูงเท่ากัน) • ปุ่มย่อ 14px ในตารางสูง 40px เท่ากันทุกจอ (ล็อก line-height กันอีโมจิดันสูง)
- ปุ่มย้อน `‹` มีทุกจอ ยกเว้นจอแรก (ทริปของฉัน) • ฟอร์มเพิ่ม/แก้พับไว้ กดค่อยกาง + ปุ่มบันทึกทุกครั้ง
- Layout: `.wrap` เดียว max-width 560px ทุกจอเท่ากัน • ตารางไม่มี scroll แนวนอน แต่ปุ่มในเซลล์ซ้อนแนวตั้งเองเมื่อจอแคบกว่า 480px

## 4. สเปกทีละจอ (ย่อ — ดูภาพเต็มใน ux-prototype.html)

1. **ทริปของฉัน:** การ์ดทริปละใบ (ชื่อ/วัน/คน/ป้ายสถานะ/ปุ่ม ▶ ทำต่อ + ✏️ แก้) + เพิ่มทริป — ไม่มีการกรอกบนการ์ด ไม่มีแถบขั้นบนการ์ด • ปุ่มทำต่อมี 3 ปลายทางตามสถานะทริป (ยังไม่อนุมัติ→เทียบ / อนุมัติแล้ว→จดเงิน / จบแล้ว→สรุป)
2. **ตารางเทียบ (ศูนย์กลาง):** ตาราง 1 แถว = 1 ใบ แตะแถวเปิดใบได้เลย (ปลายทาง/คืน/คร่าวๆ/ข้อดี/ยอดละเอียดถ้ามี) + ปุ่ม ★/✏️ คู่กันแบบย่อ + ปุ่มเคาะเฉพาะใบที่กรอกแล้ว + กล่องขอเบิกของใบตัวจริง (ยอดใหญ่ + ล็อก + ปุ่มออกเดินทาง) + เพิ่มตัวเลือก
3. **ใบรายละเอียด (โครงเดียวกับจดเงินจริงเป๊ะ):** ทุกหมวด = การ์ดหัวข้อยอดรวม + แถวรายการ (หัวข้อ+ยอด+โน้ต) + ฟอร์ม +เพิ่มรายการ พับไว้กางออกมากรอกแล้วบันทึก • ที่พักเก็บราคา/คืน×คืนไว้ในฟอร์มเพิ่ม • กิจกรรมเก็บค่าเข้า/คน×จำนวนคนไว้ในแถว + ปุ่มกลับไปเคาะที่ตารางเทียบ
4. **จดเงินจริง:** สมุดบัญชีทีละรายการแยก 4 หมวด (หัวข้อ+ยอดทุกครั้ง โน้ตไม่บังคับ) + ฟอร์มเพิ่มพับไว้ กด + ค่อยกาง + หัวหมวดและหัวจอโชว์แผน/ใช้ไป/เหลือ-เกิน + รวมล่างสุด + ปิดทริป
5. **สรุปจบทริป:** อ่านอย่างเดียว (แผน vs จริง) เก็บเป็นบทเรียน

## 5. แผนรื้อโค้ด (หลังพ่อผ่านต้นแบบ)

1. `store.js`: เพิ่ม `tripPhase(t)` + `totalsForCandidate` (มีแล้ว) + ยอดต่อใบ ไม่ sum ข้ามใบ
2. `main.js`: ทิ้ง `TABS` + แท็บแท็บ เปลี่ยนเป็น router 3 ระดับ (ทริป/ห้องทริป/ใบ) + phase stepper
3. `pages/`: ตารางเทียบเป็นศูนย์กลาง (เทียบ+เคาะ+ขอเบิกในจอเดียว) ไม่แยกจอขออนุมัติ — เก็บกฎปุ่ม: หลักเต็มกว้างทึบ/รองแถวเดียวกันโปร่ง/ในตารางใช้ปุ่มย่อ
4. เทส: เปิดแอป → ทำต่อ → คุย → ลงละเอียด → เคาะ → จดจริง → สรุป ครบ 1 รอบบนมือถือ
