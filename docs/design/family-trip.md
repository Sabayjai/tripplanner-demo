# Design · Trip Planner ครอบครัว (R002)

## 1. ภาพรวมการออกแบบ (Architecture Overview)
- รูปแบบ: Web App 5 หน้า (Vite + JS แยกไฟล์) Frontend อย่างเดียว ไม่มี backend
- เทคโนโลยี: Vite (แยกไฟล์แก้ทีละหน้า) + localStorage ก้อนเดียว `trips` + ภาษาไทยล้วน มือถือเป็นหลัก Responsive จอใหญ่
- เหตุผล: พ่อใช้คนเดียว ดูบนเครื่องพ่อ ไม่แชร์/export แยกไฟล์แก้เลย์เอาต์มือถือง่ายกว่าไฟล์เดียว

## 2. โครงสร้างข้อมูล (Data Model) — ก้อนเดียว
- `trips[]` เก็บใน key `trips`:
  - Trip: id, ชื่อ, วันที่, ผู้ใหญ่/เด็ก, สถานะ (ร่าง/วางแผน/สรุปแล้ว)
  - Candidate[]: id, ปลายทาง, คืน, งบคร่าวๆ, เลือกไปลงละเอียด (true/false)
  - Plan (เฉพาะที่ติ๊ก): travel {พาหนะ=รถส่วนตัว, น้ำมัน, ทางด่วน, จุดแวะ[]}, stay {ชื่อ, ราคา/คืน, คืน, รวม=ราคาxคืน}, activities[] {ชื่อ, สถานที่, ค่าเข้า/คน, หมายเหตุเด็ก, ใครเสนอ, ที่ตั้ง=ระหว่างทาง/ใกล้ที่พัก}
  - Budget {เดินทาง, ที่พัก, กิน, กิจกรรม} — ดึงจากรายละเอียดมารวมอัตโนมัติ แก้เพิ่มได้
  - Actual {เดินทาง, ที่พัก, กิน, กิจกรรม} — คนละชุดกับ Budget จดหลัง Finalize
  - Finalize {แผนที่ล็อก id, ล็อกแล้ว true/false, งบสุดท้าย}
- ป้ายกลุ่มอัตโนมัติตามหน้าที่กรอก: หน้าเดินทาง→เดินทาง, หน้าที่พัก→ที่พัก, หน้ากิจกรรม→กิจกรรม, ช่องกินในหน้างบ→กิน
- ปุ่มคัดลอกข้ามทริป: copy ทั้งทริป หรือดึงเฉพาะเดินทาง/ที่พัก/กิจกรรมจากทริปเก่า

## 3. หน้าจอ 5 หน้า + ภาพรวมไม่หลง
- 1 ลิสต์ทริป / 2 Candidate แบบการ์ดแนวตั้ง / 3 รายละเอียด / 4 งบ+จดจริง / 5 สรุป 1 หน้า
- แถบยอดรวมบนทุกหน้า: เดินทาง+ที่พัก+กิน+กิจกรรม = รวม อัปเดตทันที
- หน้าสรุป: ยอดขอเบิกใหญ่สุดบนสุด → การ์ด Candidate → แผนที่เลือกกรอบสี → งบ 4 หมวดบรรทัดๆ มือถือเลื่อนลง จอใหญ่เรียง 3 คอลัมน์

## 4. กฎสำคัญ (Contracts)
- ทุกช่องไม่บังคับกรอก เว้นว่างได้ บันทึกได้เลย งบรวมเฉพาะที่มี
- กรอกเฉพาะแผนที่ติ๊กไปลงละเอียด ไม่ต้องกรอกทุก Candidate
- Finalize ได้ 1 แผน/ทริป ล็อกแผน+งบทั้งหมด Actual จดได้อย่างเดียว แก้ต้องปลดล็อกก่อน
- หน้าสรุปอ่านอย่างเดียว ไม่แชร์/export ดูบนเครื่องพ่อ

## 5. ข้อแลกเปลี่ยน (Trade-offs)
- ก้อนเดียวค้นข้ามทริปช้ากว่านิดหน่อย แต่ใช้จริงเปิดทีละทริปไม่มีผล
- localStorage เก็บเป็น text (~5MB) แต่เป็นตัวหนังสือล้วนไม่มีรูป เก็บได้เป็นร้อยทริป แอปแปลงตัวเลข/วันที่ให้เอง
- แยก 5 หน้าต้องมีปุ่มย้อนกลับชัดๆ แลกกับไม่ต้องเลื่อนยาวจนตาลาย
